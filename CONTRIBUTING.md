# Contributing

Thanks for your interest! This is a personal, experimental project and I'm
**not accepting contributions** — please don't open pull requests or feature
requests, as I won't be able to review or merge them.

You're very welcome to **fork** the repository and adapt it for your own use.
It's dual-licensed under [MIT](LICENSE-MIT) OR [Apache-2.0](LICENSE-APACHE), so
you can build on it however you like.
